Individual Project

E-Commerce Web Application

A full-stack e-commerce web application developed using C#, ASP.NET MVC, Entity Framework Core, and SQL Server. The application allows customers to browse products, view product details, and manage shopping cart items, including adding or removing products and updating quantities.

It includes user registration and authentication using ASP.NET Core Identity, along with an administrative interface for managing products, users, and orders. Product images are uploaded to the wwwroot directory, with their file paths stored in the database. The application also includes integration with an external payment gateway for electronic payments.

Key Features:

  • Product browsing and detailed specification views
  • Full CRUD functionality for product management
  • User registration & authentication via ASP.NET Core Identity
  • Shopping cart management with dynamic quantity updates
  • Administrative management for products, users, and orders
  • Secure file upload handling for product media (wwwroot)
  • External payment gateway integration for transactions
  • MVC architecture structured with EF Core Code First
C# ASP.NET MVC ASP.NET Core Identity EF Core SQL Server HTML5 CSS3 JavaScript

Individual Project

Student Management System

A console-based student management application developed in C++. The application enables users to add, view, search, update, and delete student records, as well as enter and display student grades.

The project applies Object-Oriented Programming principles and uses classes and objects to organize the code. Student data is managed in memory during program execution.

Key Features:

  • Add and view student demographic and academic records
  • Search student records efficiently by identification
  • Update existing student information and coursework
  • Delete obsolete student entries
  • Enter, compute, and display student grade metrics
  • Applies fundamental OOP concepts (encapsulation and abstraction)
  • Robust input parsing and structured memory handling
C++ Object-Oriented Programming Data Structures Console Application
